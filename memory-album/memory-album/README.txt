SETUP (VS Code)
1. Photos: drag your images into the "photos" folder.
   Then open index.html and edit the PHOTOS list near the bottom
   (search for "EDIT THIS LIST") so it matches your file names.
2. Sound: put your audio file in this folder named sound.mp3
   (also checks sound.m4a, sound.ogg, sound.wav). It loops until the tab is closed.
3. Test: right-click index.html -> Open with Live Server (or just open it in a browser).
   Keep your volume low while testing.
4. Deploy: vercel.com -> Add New -> Project -> drag this whole folder in
   (Framework: Other, no build command) -> Deploy.
